Nuevo estudiante

Los apellidos y nombres se unirán automáticamente como APELLIDOS + NOMBRES y se guardarán en MAYÚSCULAS. El código se genera exclusivamente en el servidor para evitar duplicados.

Nuevo horario

No se permiten dos horarios para la misma combinación DÍA + GRADO + SECCIÓN. La hora de salida debe ser posterior al ingreso. Las horas se guardarán como hora real en Sheets y se mostrarán como HH:mm:ss.

Nuevo docente

🛡️ El rol DOCENTE está fijado por el servidor. No existe un control para crear o asignar ADMINISTRADOR desde esta página.
